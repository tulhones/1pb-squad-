01 · Cadência semanal

Como opera cada semana

Três semanas com ritmo idêntico. A newsletter é escrita primeiro e vira o script do YouTube — nunca o contrário. Gravar no domingo com script pronto elimina improvisação. Batch na segunda garante que a semana toda já está pronta antes de começar. Publicação diária no piloto automático.

Rotina Semanal Fixa
Repete nas 3 semanas de abril
SÁBADO
Escrita NL
Escrever as 2 newsletters da semana usando o framework APVG (sessão de criação — 90 min). NL1 "O Sistema da Semana" (prática, Vantagem mais pesada). NL2 "A Ideia da Semana" (filosófica, Perspectiva mais pesada). Salvar os rascunhos. Deixar incubar 24h antes da edição final.
DOMINGO
Revisão + Gravação
Bloco 1 — Revisar e finalizar as 2 newsletters (sessão de edição — 45 min): cortar 20% do texto, verificar fluxo, polir gancho e gamificação. Deixar pronto para agendar na segunda.
Bloco 2 — Gravar os 2 vídeos do YouTube usando a newsletter como script (12–15 min cada). A newsletter JÁ É o roteiro — adapte para o formato falado. Sem edição agora. Só gravar e conferir áudio/imagem.
SEGUNDA
EdiçãoBatch IG
Manhã: editar e subir os 2 vídeos do YouTube (thumbnail + descrição + tags). Agendar as 2 newsletters no Substack/Kit — NL1 para terça, NL2 para quinta.
Tarde — Batch completo via agentes: extrair todo o conteúdo Instagram da semana A PARTIR DAS NEWSLETTERS — reels + carrosséis + tweets/threads + stories. A newsletter já tem os insights prontos: só formatar para cada canal. Agendar tudo.
TER → SÁB
ReelCarrossel
Publicação automática: 1 reel + 1 carrossel por dia, já agendados na segunda-feira. Stories de bastidores diários (5 min por dia).
