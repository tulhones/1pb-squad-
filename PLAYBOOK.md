# 1PB Squad — O Playbook
**Guia de qual agente chamar para cada situação do seu negócio**

---

> **Como usar este guia**
> Encontre abaixo a situação mais parecida com o que você precisa fazer agora.
> Ative o agente recomendado digitando o comando no Claude Code.
> Você não precisa usar todos os 150. Use os certos para o momento certo.
